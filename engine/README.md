# Engine

Put the portable Godot **4.7.2** Windows build here (not stored in git, it's 180 MB):

- `Godot_v4.7.2-stable_win64.exe`
- `Godot_v4.7.2-stable_win64_console.exe`

Download "Godot Engine 4.7.2 - Standard - Windows 64-bit" from https://godotengine.org/download/archive/
and unzip both files into this folder. The launchers in the main folder find them automatically.
